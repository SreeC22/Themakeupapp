Pill-shaped primary action, warm and inviting; use `primary` (clay) for the main CTA, `quiet` (ink) for a confident secondary, `soft`/`ghost` for lower emphasis.

```jsx
<Button variant="primary" size="lg" full>Take the 30-second quiz</Button>
<Button variant="ghost">Skip for now</Button>
```

Variants: `primary` · `quiet` · `soft` · `ghost`. Sizes: `sm` · `md` · `lg`. Props: `full`, `icon`, `disabled`.
