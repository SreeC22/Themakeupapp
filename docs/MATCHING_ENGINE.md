# Matching engine boundary

No personalized ranking engine is implemented or claimed in Stage 1.

The preview supports category and textual exploration, profile editing, evidence explanations and comparison. An alphabetic or research-date sort is not a fit score. Missing prices, formula facts, precise shades and shade compatibility must remain unknown. A budget preference is not evidence that an unknown-price product fits that budget.

For foundation and concealer, these historical listings do not establish an exact shade. For blush and lips, explain aesthetic color-family/opacity goals instead of presenting a foundation-style match chip. No confidence percentage is calibrated.

Stage 3 will implement versioned, category-specific deterministic rules with separate evidence confidence, using only verified Stage 2 facts. Proposed weights in the owner brief are hypotheses, not validated science. Required fixtures include olive temperature/saturation, concealer intent, two-toned lips, contradictory inputs, unknown data and no-exact-match paths. Those ranking tests cannot pass before the engine and verified data exist.
