# Vendored skills

Two skills copied verbatim from [vltansky/foundry-skills](https://github.com/vltansky/foundry-skills), MIT licensed, copyright 2026 Vlad Tansky. See `FOUNDRY-SKILLS-LICENSE`.

| Skill | What it does | Who uses it |
|---|---|---|
| `grill-product` | Pressure-tests a product, feature, or spec so you build the right thing. | Head of Product, for the weekly product grill. |
| `ux-reviewer` | Audits an existing UX flow or screen and tells you what to fix first. | Head of Product Design, for screen and flow reviews. |

Content is upstream verbatim, so these files use em dashes, unlike the rest of this repo. That is a deliberate fidelity choice for third-party tooling, not a relaxation of house rule 1. To update, re-copy from upstream.
