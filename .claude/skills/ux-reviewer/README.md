# UX Reviewer

Review an existing UX flow, screen, prototype, screenshot, or live product. Use when the user asks for a UX reviewer, UX audit, UX roast, brutal UX review, or to tear apart a flow.

## Installation

```bash
npx skills add vltansky/foundry-skills/skills/ux-reviewer -g -y
```

## Structure

```
ux-reviewer/
  SKILL.md              # Skill definition
  references/           # Supporting documentation (rubric)
```
